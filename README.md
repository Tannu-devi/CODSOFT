# Spam SMS Detection

## Project Description
This project detects whether an SMS message is Spam or Ham using Machine Learning.

## Dataset
SMS Spam Collection Dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- TF-IDF Vectorizer
- Multinomial Naive Bayes

## Accuracy
95.55%
